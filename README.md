# WiSense

## Wi-Fi Intelligence & Analytics

WiSense is a Data Science project focused on understanding Wi-Fi connectivity through data analysis, machine learning, spatial intelligence, and interactive visualization.

The project is built using **Python and Streamlit**.

---

## Project Goal

WiSense aims to answer:

> **What does my Wi-Fi data tell me, and how good is my network?**

The project will combine:

- Wi-Fi observation data
- Exploratory Data Analysis
- Statistical analysis
- Connectivity scoring
- Machine learning
- Network recommendations
- Spatial analysis
- Interactive visualization
- Real Wi-Fi data collection in later development

---

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Streamlit

Additional libraries will be introduced only when required by later phases.
